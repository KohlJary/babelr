# Layouts

Ophanic drawings of Babelr's interface: box-drawing text an LLM can read and write, parsed by
`ophanic parse`. They're the map of the UI. Change the drawing with the code, in the same commit.

- `chat-view.oph`: the chat view as it is (desktop, a DM, phone).
- `proposals/`: drawn, not built. A proposal moves up when it ships.

Draw separate boxes (`┌─┐` each); the parser doesn't read shared walls (`├ ┬ ┴`).
